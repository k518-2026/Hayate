# Hayate — 超高速・安全ファイルコピー

Windows デスクトップアプリ（WPF / C# / .NET 8）。Visual Studio で `Hayate.sln` を開いて F5 で実行できます。外部パッケージへの依存はありません（NuGet 復元不要）。

## 必要なもの

- Visual Studio 2022（ワークロード「.NET デスクトップ開発」）
- .NET 8 SDK

## 速さのための設計

| 手法 | 効き方 |
|---|---|
| 複数ファイルの並行処理 | SSD / NVMe のキューを埋めて帯域を使い切る。既定 4 本、HDD なら 1 に落とす |
| 大きめバッファ（既定 4 MB）＋非同期 I/O | システムコール回数と待ちを減らす |
| `SequentialScan` ヒント | OS の先読みが効く |
| 事前に `SetLength` で領域確保 | 書き込みのたびのファイル拡張とメタデータ更新、断片化を避ける |
| 大きいファイルから流す | 終盤まで並列度が保たれ、進捗が素直に伸びる |
| 同一ボリューム内の「移動」はリネーム | 何 GB でも一瞬 |
| 同一内容（サイズ＋更新日時）はスキップ | 二度目以降が劇的に速い |
| ハッシュは読み込みバッファを再利用 | 検証のための追加読み込みが発生しない |
| `ArrayPool` でバッファを使い回す | GC 圧を抑える |
| UI は 200ms 間隔でまとめて更新 | 描画がコピーの足を引っ張らない |

## 安全のための設計

- **必ず一時ファイル（`.hayate-part`）に書いてから置き換える。** 途中で電源が落ちても、コピー先の既存ファイルは壊れません。中断された `.hayate-part` は自動で削除されます。
- **全バイト照合。** 書き終えた内容を読み戻し、コピー元の xxHash64 と突き合わせます。一致しなければ失敗として扱い、置き換えません。
- **閉じる前にディスクへ強制フラッシュ。** OS のキャッシュに残ったまま「完了」とは言いません。
- **移動は検証に成功した後にだけ元を消します。** 順序が逆になることはありません。
- **自動リトライ。** 一時的な I/O エラーは間隔を空けて既定 3 回まで再試行し、その間の進捗は正しく巻き戻します。
- **中断後の再開。** 完了したファイルをコピー先の `.hayate-journal` に記録し、次回は済んだ分を飛ばします（全件成功で自動削除）。
- **開始前の空き容量チェック**、**コピー先がコピー元の内側でないかの確認**、**シンボリックリンク／ジャンクションを辿らない**。
- **ドライラン。** 何も書かずに対象と件数だけ確認できます。
- 1 ファイルが失敗しても全体は止まりません。最後にエラー一覧を表示します。

## 使い方

1. ファイルやフォルダーをウィンドウにドラッグ＆ドロップ（またはボタンから追加）
2. コピー先を指定
3. 右側で動作・検証・同時処理数などを設定
4. 「開始」

一時停止・再開・中止に対応しています。

## 完了の知らせ

大量のファイルを流している間は別の作業をしていることが多いので、終わったことが席を外していても分かるようにしてあります。

- **ポップアップ**: 経過時間・転送量・平均速度・件数・失敗数をまとめて表示します。そのまま「コピー先を開く」ボタンでエクスプローラーを開けます。中止したとき、失敗が混ざったとき、ドライランのときは、見出しと色が変わります。
- **メロディー**: 成功したら上がっていく 4 音、失敗が混ざったら下がる 3 音、中止したら低い 2 音。音源ファイルは持たず、その場で PCM を組み立てて鳴らすので追加のファイルは不要です。
- どちらも右側の設定でオフにできます。

進捗表示は残り時間ではなく**経過時間**です（一時停止中は止まります）。残り時間は小さいファイルが大量にあると当てにならない値になるため、実際にかかっている時間を出す形にしています。

## 設定の目安

- **検証**: 既定は「全バイト照合」。読み戻しがある分、書き込みだけの場合より遅くなります。大量の小さいファイルを一時的に移すだけなら「検証なし」でも構いませんが、保管用のコピーでは既定のままを勧めます。
- **同時処理ファイル数**: NVMe なら 8、SATA SSD なら 4、HDD やネットワークドライブなら 1〜2。HDD で並列度を上げるとヘッドが往復して逆に遅くなります。
- **バッファサイズ**: 大きいファイル中心なら 16 MB、小さいファイルが大量なら 1 MB 前後が扱いやすい値です。

```
Hayate.sln
src/Hayate/
  Hayate.csproj
  app.manifest              長いパス対応 / 高 DPI
  App.xaml(.cs)             スタイル定義と例外ハンドラ
  MainWindow.xaml(.cs)      画面とドラッグ＆ドロップ
  CompletionWindow.xaml(.cs) 完了ポップアップ
  Core/
    CopyEngine.cs           コピー本体（並列・一時ファイル・検証・リトライ）
    CopyOptions.cs          設定と進捗の型
    FileScanner.cs          コピー元の走査
    Journal.cs              再開用の完了記録
    MelodyPlayer.cs         完了メロディー（PCM をその場で生成）
    PathUtil.cs             長いパス・重複名・表示整形
    XxHash64.cs             検証用ハッシュ（自前実装）
  ViewModels/
    MainViewModel.cs        画面ロジック
    ObservableObject.cs
    RelayCommand.cs
```

## 補足

- 管理者権限は要求しません。アクセス権のない場所を扱うときは、Visual Studio または実行ファイルを手動で昇格させてください。
- 260 文字を超えるパスは `\\?\` 表記と `longPathAware` マニフェストで扱えます。
- xxHash64 は暗号学的ハッシュではありません。転送中の化けを検出する用途に特化しています。改ざん検知が必要なら `VerifyLevel` の分岐に SHA-256 を足す形で拡張できます。
